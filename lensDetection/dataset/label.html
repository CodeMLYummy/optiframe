Étiquetage des verres


Clic : ajouter un point sur le bord extérieur du verre (inséré au bon endroit du contour). Glisser un point : le déplacer. Clic droit sur un point : le supprimer. Molette : zoom. Maj + glisser ou clic du milieu : déplacer la vue. Mode « coins » : cliquez d'abord les 4 coins du cadre imprimé (l'ordre n'importe pas), puis le contour. Tout est sauvegardé dans ce navigateur ; « Exporter » télécharge le fichier à donner à l'entraînement.
